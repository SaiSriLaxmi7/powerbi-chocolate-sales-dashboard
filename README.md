\# Power BI Chocolate Sales Dashboard



\## Overview

This project is an interactive Power BI dashboard built to analyze chocolate sales, shipments, profit, and business performance.



\## Objectives

\- Track key business KPIs

\- Analyze profit and shipment trends

\- Monitor product-level and operational performance

\- Present insights through interactive visuals



\## Tools Used

\- Power BI

\- Power Query

\- DAX

\- Excel



\## Project Files

\- `chocolate-sales-dashboard.pbix` - Power BI dashboard file

\- `data/chocolate\_shipments\_data.xlsx` - source dataset

\- `assets/` - icons and visual assets used in the report

\- `screenshots/` - dashboard preview images



\## Key Features

\- KPI cards for performance monitoring

\- Interactive slicers and filters

\- Shipment and profit tracking

\- Business-oriented visual storytelling
